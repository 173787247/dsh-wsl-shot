# dsh-wsl-shot

DeepSeek Harness 插件：把 Windows 剪贴板图片保存为 WSL 文件，供多模态会话使用。

配套 **[dsh-wsl-kit](https://github.com/173787247/dsh-wsl-kit)**。

[English → README.md](./README.md)

## 安装

```sh
dsh plugin --profile web add github:173787247/dsh-wsl-shot
```

重启 `dsh web` 并开**新**会话。工具名：`win_shot`。
